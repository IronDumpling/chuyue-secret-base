# Share Poster and Share Buttons Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every blog post and portfolio project gets a portrait poster (cover, title, short summary, QR code to the page) that can be saved and posted to WeChat Moments, Xiaohongshu or Instagram stories, plus a share bar on the page with Copy link, Save poster and system Share.

**Architecture:** Reuses the build-time renderer from plan 02. The generator renders a second image per entry, `public/share/poster/...jpg` at 1080x1920, with a QR code generated by the `qrcode` package that encodes the page's canonical URL. The share bar is a small client component that only needs URLs; it does no image work in the browser, so it behaves the same on every phone and needs no canvas or CJK font in the browser.

**Tech Stack:** satori, @resvg/resvg-js, sharp, qrcode, React client component, vitest.

**Spec:** `docs/superpowers/plans/2026-09-20-00-priorities-and-roadmap.md`

## Global Constraints

- Requires plan 02 completed (`lib/site.ts`, `lib/share-paths.ts`, `scripts/lib/card.ts`, `scripts/lib/fonts.ts`, `scripts/generate-share-images.ts` exist and `entryTexts` is exported).
- Poster size 1080x1920, JPEG quality 86. Generated into `public/share/poster/`, git-ignored, rebuilt every build.
- The QR code encodes `absoluteUrl(pagePath(entry))`, the canonical URL with base path and trailing slash.
- Share bar labels are English to match the current UI: "Copy link", "Save poster", "Share".
- Do not add any dependency to the browser bundle except what the component itself needs (none).

Add to the imports of `scripts/lib/card.ts`: `import QRCode from 'qrcode'`. Append:
```ts
export interface PosterInput {
  title: string
  badge?: string
  description?: string
  coverDataUri?: string
  qrDataUri: string
  host: string
}

const POSTER_WIDTH = 1080
const POSTER_HEIGHT = 1920
const POSTER_COVER = 1080

export async function qrDataUri(url: string): Promise<string> {
  return QRCode.toDataURL(url, {
    margin: 1,
    width: 440,
    color: { dark: '#0f172a', light: '#ffffff' },
  })
}

export function buildPosterTree(input: PosterInput): Node {
  const cover = input.coverDataUri
    ? h('img', { src: input.coverDataUri, width: POSTER_WIDTH, height: POSTER_COVER, style: { width: POSTER_WIDTH, height: POSTER_COVER } })
    : h('div', {
        style: {
          display: 'flex',
          width: POSTER_WIDTH,
          height: POSTER_COVER,
          backgroundImage: 'linear-gradient(135deg, #1e3a8a, #0f172a)',
        },
      })

  return h(
    'div',
    {
      style: {
        display: 'flex',
        flexDirection: 'column',
        width: POSTER_WIDTH,
        height: POSTER_HEIGHT,
        backgroundColor: '#0f172a',
        color: 'white',
      },
    },
    cover,
    h(
      'div',
      { style: { display: 'flex', flexDirection: 'column', flexGrow: 1, padding: '64px 72px 72px 72px' } },
      input.badge ? h('div', { style: { display: 'flex', fontSize: 32, opacity: 0.8, marginBottom: 20 } }, input.badge) : null,
      h('div', { style: { display: 'flex', fontSize: 72, fontWeight: 700, lineHeight: 1.2 } }, clip(input.title, 36)),
      input.description
        ? h('div', { style: { display: 'flex', fontSize: 34, lineHeight: 1.5, opacity: 0.75, marginTop: 28 } }, clip(input.description, 90))
        : null,
      h('div', { style: { display: 'flex', flexGrow: 1 } }),
      h(
        'div',
        { style: { display: 'flex', alignItems: 'flex-end', justifyContent: 'space-between' } },
        h(
          'div',
          { style: { display: 'flex', flexDirection: 'column' } },
          h('div', { style: { display: 'flex', fontSize: 40, fontWeight: 700 } }, 'Chuyue · System Designer'),
          h('div', { style: { display: 'flex', fontSize: 28, opacity: 0.7, marginTop: 12 } }, `Scan to read · ${input.host}`)
        ),
        h(
          'div',
          { style: { display: 'flex', padding: 12, backgroundColor: 'white', borderRadius: 16 } },
          h('img', { src: input.qrDataUri, width: 220, height: 220, style: { width: 220, height: 220 } })
        )
      )
    )
  )
}
```
`clip` already exists in this file from plan 02 (used by `buildCardTree`).

- [ ] **Step 5: Create the client component**

Create `components/shared/ShareBar.tsx`:
```tsx
'use client'

import { useEffect, useState } from 'react'
import { withBasePath } from '@/lib/utils'

interface ShareBarProps {
  title: string
  url: string
  posterPath: string
  filename: string
}

const buttonClass = 'button-secondary inline-flex items-center gap-2 text-sm'

export default function ShareBar({ title, url, posterPath, filename }: ShareBarProps) {
  const [copied, setCopied] = useState(false)
  const [canShare, setCanShare] = useState(false)

  // navigator.share only exists in some browsers; decide after mount to keep server and client HTML identical.
  useEffect(() => {
    setCanShare(typeof navigator !== 'undefined' && typeof navigator.share === 'function')
  }, [])

  const copyLink = async () => {
    try {
      await navigator.clipboard.writeText(url)
      setCopied(true)
      setTimeout(() => setCopied(false), 2000)
    } catch {
      window.prompt('Copy this link', url)
    }
  }

  const systemShare = async () => {
    try {
      await navigator.share({ title, url })
    } catch {
      // user cancelled the share sheet; nothing to do
    }
  }

  return (
    <div className="flex flex-wrap gap-3 mb-8" aria-label="Share this page">
      <button type="button" onClick={copyLink} className={buttonClass}>
        {copied ? 'Copied' : 'Copy link'}
      </button>
      {/* download works on desktop and Android; iOS Safari opens the image instead, where a long press saves it */}
      <a
        href={withBasePath(posterPath)}
        download={filename}
        target="_blank"
        rel="noopener noreferrer"
        className={buttonClass}
      >
        Save poster
      </a>
      {canShare && (
        <button type="button" onClick={systemShare} className={buttonClass}>
          Share
        </button>
      )}
    </div>
  )
}
```
